# 💬 پیام‌رسان v4.0

## ⚙️ تنظیم
فایل `config.js`:
```js
BALE_BOT_TOKEN: 'توکن_ربات_بله',
```

## 🚀 نصب
```bash
npm install
npm start
```

## 🌐 آدرس‌ها
- پیام‌رسان: http://localhost:3000
- پنل ادمین: http://localhost:3000/panel-Tk_tokyo
- رمز: Tk_tokyo

## ✨ قابلیت‌های جدید v4
- دیتابیس SQLite (اطلاعات ذخیره میمونه)
- ورود با ربات بله + OTP
- یه آیدی = یه حساب
- ارسال عکس، فایل، ویس
- ویرایش و حذف پیام
- ریپلای، فوروارد، پین پیام
- واکنش ایموجی
- پیام ناپدیدشونده
- گزارش پیام
- بلاک دائمی/موقت از پنل ادمین
- اطلاع‌رسانی بلاک از طریق بله
- قوانین با مدیریت از پنل
- حالت به‌روزرسانی سرور
- لوکیشن اجباری + آپدیت هر ۶۰ ثانیه
- محدودیت ایران (GPS + IP)
- نمودار آمار روزانه
- پروفایل + بیو + عکس پروفایل
- وضعیت آنلاین/مشغول/غایب
